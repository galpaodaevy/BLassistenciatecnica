# BL Assistência Técnica

Página leve para pedidos pelo WhatsApp, com celulares, tablets e notebooks.

O visitante informa marca, modelo, serviço desejado e o que aconteceu. O botão abre o WhatsApp com a mensagem preenchida; o visitante precisa tocar em enviar. Não há envio automático, agendamento nem armazenamento dos pedidos no site.

Contato configurado: 5511930919355 · blassistencia107@gmail.com.

Os arquivos prontos para hospedagem estão em `dist/`. Para alterar o número, atualizar `dist/message.js` e os links de contato em `dist/index.html`.

As opções representam problemas relatados pelo cliente. A BL confirma disponibilidade do atendimento, orçamento e prazo na conversa.
